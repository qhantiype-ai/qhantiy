# Qhantiy — Revista Universitaria

Sitio web estático y adaptable para Qhantiy, con identidad visual en crema, marrón y dorado viejo.

## Cómo abrirlo
1. Descomprime `qhantiy-web-final.zip`.
2. Abre `index.html` en un navegador moderno.
3. La fuente League Spartan y Over the Rainbow se cargan desde la carpeta `assets`.

## Secciones
- Inicio / portada de Qhantiy.
- Quiénes somos.
- Investigaciones dentro de la misma página.
- Contacto con Instagram y correo.

## Publicaciones
El botón “Administrar publicaciones” es una demostración local: guarda los artículos en el almacenamiento del navegador donde se crean. No publica artículos en internet ni sincroniza entre dispositivos. Para que el equipo pueda actualizar publicaciones online, se debe conectar un CMS y desplegar el sitio en un servicio de hosting.
